# Threshold

A synthetic eligibility workbench for six Washington, DC energy programs.

## Current preview

The deployed preview includes a landing page, household queue, deterministic eligibility calculations, household detail, enrollment stages, manual synthetic intake, a program catalog, browser activity, and a household view. Records and changes are stored in the browser. This preview does not connect to production services.

## Run locally

    pnpm install
    pnpm dev
